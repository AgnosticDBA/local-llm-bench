# Senior Database Reliability Engineer — Halvorsen Freight Systems (fictional)

*This posting is invented for benchmarking. The company does not exist.*

Location: Rotterdam, Netherlands (hybrid, two office days a week)
Team: Platform Engineering, Data Infrastructure squad

## About the role

Halvorsen Freight Systems runs the booking, tracking and invoicing platform used by 4,000 logistics
companies across Europe. Our data layer is about 180 PostgreSQL clusters on AWS plus a small SQL Server
estate we inherited from an acquisition. You will join a squad of five engineers who own the reliability,
performance and cost of that data layer, end to end.

## What you will do

- Own the availability and performance of business-critical PostgreSQL clusters running on Amazon RDS and on EC2.
- Design and run backup, restore and disaster-recovery procedures, and prove them with regular restore tests.
- Lead incident response for database outages and write blameless post-incident reviews.
- Automate provisioning and configuration of database infrastructure with Terraform.
- Tune slow queries and schema designs together with product engineering teams.
- Plan and execute major-version PostgreSQL upgrades with minimal downtime.
- Build observability for the data layer: metrics, dashboards and alerting in Prometheus and Grafana.
- Migrate the remaining SQL Server workloads to PostgreSQL over the next 18 months.
- Mentor two mid-level engineers and review their designs.

## What you bring

### Must have

- At least 7 years of hands-on experience operating PostgreSQL in production.
- Deep knowledge of PostgreSQL replication, high availability and failover tooling such as Patroni.
- Experience running databases on AWS, including RDS and Aurora.
- Strong scripting skills in Python or Go for operational automation.
- Infrastructure as code with Terraform in a team setting.
- Experience participating in an on-call rotation for production systems.
- Fluent written and spoken English.

### Nice to have

- Hands-on experience with Microsoft SQL Server administration.
- Experience with Kubernetes operators for databases, such as CloudNativePG.
- Experience with change data capture or streaming with Kafka or Debezium.
- Familiarity with cost optimisation of cloud database spend.
- A working knowledge of Dutch.
